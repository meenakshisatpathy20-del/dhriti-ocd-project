## How to read this

- **Not comparable to the study's model scores.** Dhriti's offline agent was designed using the study's findings (the pressure tactics, the risk-framing failure), and it is graded by a heuristic grader, not the blind LLM judge. It shows Dhriti behaves as designed on these scenarios; it is not an independent benchmark result.
- **Controls matter.** A system that refuses everything would pass the OCD tasks and fail the controls. Failing C06 (a general religious question) reflects that the offline agent has no general knowledge; with a language model connected, that question is answered by the model under Dhriti's guardrails.
- To grade with the original LLM judge, export these transcripts and run them through OCD-EVAL's `graders/judge_grade.py`.
