# Dhriti and Wispr Flow

Dhriti was built for the **Scaler × Wispr Flow "India Runs on Voice"** hackathon (Healthcare track) and its theme: tools where voice is the main way in, built by talking rather than typing.

## In the product

- **Voice-first everywhere.** Every screen's main input is the voice orb.
- **Wispr Flow mode** (Profile → *Wispr Flow mode*): switches every voice input to a text box. Wispr Flow types wherever the cursor is, in any language, with mid-sentence switching, so users on browsers without speech recognition (e.g. Firefox, some desktop setups) still use Dhriti entirely by voice.
- **"Type instead"** on every voice input accepts Wispr Flow dictation too; the professional chat, KYC bio and diary are dictation-friendly.
- Text from Wispr Flow goes through exactly the same pipeline as browser speech: safety screen, NLP, agent, guardrails.

## In how it was made

The project was developed hands-free with Wispr Flow: prompts, specifications and documentation were dictated into the editor and AI tools. The hackathon submissions (Idea, Prompt, Impact) are reflected in the features above: the voice panic button, reassurance guard, spoken OCI-R/Y-BOCS screening and the OCD eval.
